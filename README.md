# App_Cafetin
App pensada para ayudar a llevar el control de un cafetín pequeño sin complicarse la vida. Permite registrar ventas del día a día, anotar los fiados de los clientes y hacer seguimiento de lo que deben. La idea es tener todo más ordenado, evitar cuentas perdidas y facilitar la gestión del negocio con una herramienta simple, práctica y hecha a medida para este tipo de emprendimientos.
